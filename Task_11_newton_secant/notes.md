# Task 11 – Root Finding: Newton-Raphson and Secant Methods

## B. Inputs and Mathematical Operation
**Inputs:** Cash flow series [-10000, 3000, 3500, 4000, 2500]  
**Operations:** Find the Internal Rate of Return (IRR) using Newton-Raphson (with derivative) and Secant method.

## C. Parameter Change
Changed the initial investment from -10000 to -12000.  
Result: The IRR decreased because a larger investment needs a higher return to break even.

## D. Meaning of the Output
The IRR is the interest rate that makes the Net Present Value equal to zero. Both methods give almost the same answer.

## E. Modified Real-World Case
**New problem:** Finding the interest rate for a different investment project.  
**New cash flows:** [-15000, 4000, 5000, 6000, 3000]  
**Interpretation:** Helps decide whether the project is profitable compared to other investments.
